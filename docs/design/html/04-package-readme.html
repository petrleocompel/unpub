my_company_core

1.4.0

Core models, the HTTP client and error types shared by every Company app.

Published 3 days ago by jane.doe@company.example 48 213 downloads
DartLatest
README Changelog Versions 14 Install Stats

Features #

One package for what every Company app needs before it can talk to a backend:

  • Typed models for Customer, Order and Money, with JSON round-trips.
  • An ApiClient with retries, request ids and the Company auth header.
  • One AppError hierarchy, so every screen shows the same messages.

Getting started #

Add the package from the Company registry, then create one client per app:

final client = ApiClient(
  baseUrl: Uri.parse('https://api.company.example'),
  tokens: CompanyAuth.instance,
);

Handling errors

Every call returns a Result. Map AppError.network to the offline banner and everything else to a toast.

Configuration #

OptionDefaultMeaning
retries3Attempts for idempotent requests
timeout20 sPer request
